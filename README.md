# dbt Charts POC

A proof of concept for exploring dbt metadata and model lineage through charts.

## Overview

This repository is intended to demonstrate how dbt project artifacts can be
transformed into charts for visualizing data lineage and model relationships.
The implementation is currently in an early proof-of-concept stage.

## Goals

- Explore dbt model lineage and dependency data
- Present dbt metadata in a clear, interactive chart
- Identify useful data transformations and visualization patterns
- Establish a lightweight foundation for future development

## Status

This project does not yet contain an application or documented setup command.
The repository currently provides the starting point for the proof of concept.

## Repository layout

The repository is intentionally small at this stage:

## Getting started

Add dbt project configuration and the charting implementation before running
the POC. Until then, no build or application commands are available.
